# Task Links

Share a preconfigured local script through an expiring, revocable link that lets someone run only that task.
Make delegation effortless for the sender and recipient while keeping execution on the owner's machine.

Every link opens a simple web interface that works across different kinds of tasks.
Recipients can provide input, follow progress, view output, and see execution details such as resource usage.
The owner defines which inputs recipients can supply and which information the interface displays, keeping everything else private.

Owners can limit and stop execution, including tasks already running.
Recipients need only a browser, and owners use a single Task Links binary to connect their machine and share existing scripts.
